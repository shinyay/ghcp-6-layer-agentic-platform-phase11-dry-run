# Master Plan — 6-Layer Agentic Platform Workshop

> **このリポジトリは、60分 keynote プレゼンテーション「Agentic Development Journey」の聴講者にプレゼントする、セルフラーニング型ワークショップ教材を構築するためのものです。**

---

## 1. プロジェクトのゴール

### 1.1 教材としてのゴール
keynote 聴講者が**自分の手で 6 層の Agentic Platform を体験**し、最終的には自分の repo に持ち帰って応用できるようになる。

### 1.2 学習者ゴール(優先順位付き)
- 🎯 **MUST(=keynote CTA)**: 自分のリポジトリに `.github/skills/<name>/SKILL.md` を1つ作って commit し、Copilot CLI または Cloud Agent から呼び出せる状態にする
- 🎯 **SHOULD**: 6 層の責務分離を**手で触って**理解する
- 🎯 **COULD**: gh aw による自動化と **Copilot Code Review Agent** によるゲートまで体験する (`.agent.md` Custom Agent は発展題材)

### 1.3 コンセプト
**「Issue Triage Skill を育てる旅」** — 1つのシナリオを通じて、6 層を順次積み上げていく。各 Step で前 Step の成果が活きる、累積的な体験を提供する。

詳細は [scenario.md](#) ※ Phase 02 で作成予定

## 2. 設計原則

| # | 原則 |

| P1 | **1つのシナリオで 6 層を積み上げる**(= 独立タスクの羅列にしない) |

| P8 | **個人 fork で完結**(組織 Owner 権限を要求しない) |

## 3. シナリオ概要(全体像)

```
Step 0  Setup           → MCP 接続、Codespaces 起動
Step 1  Memory          → Copilot Memory に triage パターンを蓄積
Step 2  Skill ⭐        → SKILL.md を書いて commit (= keynote CTA)
Step 3  Where to run    → 同じ Skill を CLI / Cloud / IDE から呼ぶ
Step 4  Automate        → gh aw で issues.opened に自動起動
Step 5  Multi-engine    → engine を Copilot/Claude/Codex で切替(任意 / API key 持ちのみ)
Step 6  Gate            → 6a: Copilot Code Review Required Check (主軸) / 6b: Custom Agent (.agent.md) — 発展題材
```

完成時の動作: **Issue が開かれる → 自動 triage → ラベル付与 + 初動コメント →(必要なら) Draft PR → Review Agent ゲート → 人がマージ**

MCP を利用する Step は教材冒頭の Setup section に **MCP verification block** を必ず含めること。block は以下 4 項目を順に含む:

| # | 項目 | 受講者の操作 | 失敗時の症状 |
|---|---|---|---|
| **V1** | `.vscode/mcp.json` が repo に同梱されていることの確認 (= template 継承確認) | ターミナルで `cat .vscode/mcp.json` または VS Code Explorer で目視 | `github` server が palette に出ない |
| **V2** | Copilot Chat → Tools palette で `github` server が **可視** であることの確認 | Chat 入力欄の Tools (🔧) アイコン → リストに `github` が並ぶ | (V1 失敗の派生) |

# v1.0.0 — Initial Public Release

GitHub Copilot を学ぶための **6 layer × 7 step ハンズオン教材** の初回公開リリースです。

## 🎯 What is this?

Codespaces で起動するだけで、Copilot Memory / Skills / MCP / Cloud Agent / GitHub Models / Gates を **連続した 1 本の Trust thread** として体験できる教材です。各 Step は前 Step の成果を前提とし、最終的に「自分の repo に Copilot を統合する」開発体験を構築します。

## 🚀 Quick Start

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/shinyay/ghcp-6-layer-agentic-platform?quickstart=1)

1. 上のボタンで Codespaces を起動
2. `content/README.md` を開いて Step 0 から開始
3. 体感所要時間: 全 7 Step 通しで ~3〜4 時間 (degraded path = ~2 時間)

## 📚 Layers / Steps

| Layer | Step | 内容 |
|---|---|---|
| L0 Setup | Step 0 | Codespaces / プラン確認 / 前提整備 |
| L1 Memory | Step 1 | Copilot Memory + custom instructions |
| L2 Skills | Step 2 | Custom skill / chatmode / prompt の構成 |
| L3 Surfaces | Step 3 | Issue Assignees / Cloud Agent / MCP の境界 |
| L4 Automate | Step 4 | gh-aw による workflow 自動化 |
| L5 Multi-engine | Step 5 | GitHub Models / 複数 LLM 連携 |
| L6 Gate | Step 6 | Required Check / 品質ゲート |

## ✅ Verified

- Phase 03〜10 で全 Step を内部実機で完走 (Trust thread 連結性確認済)
- Phase 11 で **本人実機 dogfooding 1 take 完走** (E10 + E11 5 variant = 6 evidence rows)
- Phase 11 で公開リリース hardening 完了 (LICENSE / CONTRIBUTING / SECURITY / RELEASE_NOTES / ISSUE_TEMPLATE)
- 全 9 jobs CI (step-gate ×7 + smoke + pages) が ubuntu-latest 上で緑

## 📋 Prerequisites

- GitHub アカウント
- Copilot プラン (Pro 以上推奨。一部 Step は Pro+ / Business+ 機能を含む = degraded path で skip 可能)
- 任意: OpenAI / Anthropic API key (Step 5 multi-engine の一部で使用、未設定でも degraded で完走可)

## ⚠️ Known Limitations

- 一部 Step 3/5 機能 (Cloud Agent / MCP / GitHub Models 一部) はプラン依存。未対応プランでは **degraded path** に従い skip 可能。
- 本リポジトリは個人 owner で運用しています。エンタープライズ展開時は org 配下に fork + secrets 再設定を推奨。
- Phase 03 dogfooding evidence の一部 ([phase3-dry-run#8](https://github.com/shinyay/ghcp-6-layer-agentic-platform-phase3-dry-run/pull/8)) は private repo 由来のため学習者から不可視 (Phase 12+ で対応予定)。

## 🧭 What is this?

60 分の keynote「Agentic Development Journey」の聴講者にプレゼントするセルフラーニング型ワークショップ。シナリオは **「Issue Triage Skill を育てる旅」** ─ 1 つの実用的なシナリオを Step 0–6 として段階的に育て、最終形では GitHub Copilot の **6 層すべて** が協働して動く構成を体験する。

| Layer | 構成要素 | Step |
|---|---|---|
| 0 | MCP (GitHub MCP Server / WorkIQ 紹介) | Step 0 |
| 1 | Copilot Memory | Step 1 |
| 2 | Customizations (Skills / AGENTS.md / Custom Agent) | **Step 2 ⭐ keynote CTA** |
| 3 | 実行サーフェス (CLI / IDE / Cloud Agent) | Step 3 |
| 4 | gh aw (Agentic Workflows) | Step 4 |
| 5 | Agent HQ (任意) | Step 5 |
| 6 | Code Review Agent + Custom Agent Required Check | Step 6 |
